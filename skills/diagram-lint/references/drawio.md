# draw.io

Topology diagrams are generated by a Python script, `diagrams/make_diagrams.py`.
It loads `scripts/drawio_lib.py` by path, as `examples/diagrams/make_diagrams.py`
does, and writes one `.drawio` file per diagram.

## API

| Call | Does |
|------|------|
| `Doc(name, width, height)` | Creates a page. Coordinates are absolute pixels |
| `d.node(value, x, y, w, h, style)` | Adds a box and returns its id |
| `d.person(value, x, y, w, h)` | Adds a C4 person icon |
| `label(title, tech, desc)` | Builds a C4 HTML label |
| `d.vlink(a, b, value, style, lane, label_pos, jump)` | Draws one vertical segment at x `lane` |
| `d.hlink(a, b, value, style, lane, label_pos, jump)` | Draws one horizontal segment at y `lane` |
| `d.elbow(a, b, value, x, y, style, first, label_pos, jump)` | Draws two segments through corner `(x, y)`. `first` is the leg leaving `a`: `"v"` or `"h"` |
| `d.route(a, b, value, corners, style, label_pos, jump)` | Draws segments through `corners`. Consecutive corners must share x or y |
| `d.edge(src, dst, value, style, label_pos, points, jump)` | Draws a raw edge. Prefer the pinned calls above |
| `anchor(exit_at, entry_at)` | Builds exit and entry style fractions for a raw edge |
| `d.write(path)` | Writes the `.drawio` file |

Node styles: `S_PERSON`, `S_SYSTEM`, `S_CONT`, `S_DB`, `S_EXT`, `S_BOUND`.

Edge styles: `S_EDGE`, `S_EDGE_HL`, `S_EDGE_DASH`.

`label_pos` slides a label along its edge: `-1` source, `0` middle, `1` target.

## Layout

Pin every edge, or `check_layout.py` cannot prove its route. Use the simplest call
that works, in this order:

1. `vlink` or `hlink`
2. `elbow`, where a straight lane is impossible
3. `route`, where an elbow is impossible

Leave a 180 px gutter between neighbours in a band. Narrower gutters put edge
labels on the next node's caption, which the geometry check cannot see.

## Line jumps

A crossing fails the check unless the later edge carries `jump=True`. Use one only
if the diagram's requester asked for it or no crossing-free route exists.

- Emit the jumping edge after the edge it crosses. draw.io draws the jump only on
  the later edge.
- A curved edge also needs `curveGeometry=1`.
- `preview.py` does not draw jumps. Check them in the real render.

## AWS icons

The library has no AWS helper, so pass a stencil style to `d.node`:

```python
AWS_ICON = (
    "outlineConnect=0;fontColor=#232F3E;fillColor=#7AA116;strokeColor=#ffffff;dashed=0;"
    "verticalLabelPosition=bottom;verticalAlign=top;align=center;html=1;fontSize=11;"
    "aspect=fixed;shape=mxgraph.aws4.resourceIcon;resIcon=mxgraph.aws4.{name};"
)
d.node("Greengrass", x, y, 78, 78, AWS_ICON.format(name="greengrass"))
```

**Unknown stencil names render blank, with no error.** Check each new name against
[`aws4.xml`](https://raw.githubusercontent.com/jgraph/drawio/dev/src/main/webapp/stencils/aws4.xml),
writing its spaces as underscores. Plausible names can be wrong: `iot_greengrass`
and `s3_glacier` do not exist, but `greengrass` and `glacier` do. Render and inspect
any new stencil name, including `mxgraph.c4` ones.

**Connect verticals only to an icon's caption-free side.** The caption sits outside
the icon's rectangle, so `check_layout.py` passes a line that cuts through it. To
take verticals from below, move the caption above the icon with
`verticalLabelPosition=top;verticalAlign=bottom`, and take none from above.

## Other logos

Use the first option that works:

1. A draw.io stencil.
2. The vendor's own SVG, from its brand or press page, committed as
   `diagrams/icons/<vendor>-<product>.svg`. Do not use third-party icon collections.
3. A C4 box with the product name.

Every committed logo must follow these rules:

- **Recorded:** add a row to `diagrams/icons/README.md` with the file, product,
  source page, date and what the page says about documentation use. If no such
  statement can be found, do not use the logo.
- **Unaltered:** do not recolour or crop it, or imply the vendor endorses the system.
  The vendor's guidelines take precedence.
- **Safe:** reject any SVG with a `<script>`, an external `href` or an embedded font
  reference.
- **Committed:** never fetch a logo at build time.

Embed the logo at 78 px. The caption rule above applies. Omit `;base64` from the data
URI, because `;` separates style keys (confirmed on draw.io 31.7.0):

```python
data = base64.b64encode((HERE / "icons/vendor-product.svg").read_bytes()).decode()
style = (
    "shape=image;verticalLabelPosition=bottom;verticalAlign=top;html=1;aspect=fixed;"
    f"image=data:image/svg+xml,{data};"
)
d.node("Product", x, y, 78, 78, style)
```

## Checks

- **`check_layout.py`** fails on a line through a node, a crossing without a valid
  jump, two lines drawn on top of each other, or an anchor outside its node. It
  reports any route it cannot predict as `UNVERIFIED`.
- **`content_diff.py`** compares node labels, edges and which nodes each boundary
  box contains. It ignores ids, anchors, waypoints and coordinates, and exits 1
  with every difference.
- **`preview.py`** writes a gitignored `<name>.preview.svg`. It shows rectangles and
  routes only, so it does not replace the real render.

## Rendering

Install [draw.io desktop](https://github.com/jgraph/drawio-desktop/releases) and put
it on `PATH` as `drawio`. On macOS, the `Makefile` also checks
`/Applications/draw.io.app`.

```bash
make sources  # regenerate the .drawio files
make check    # run the geometry check
make          # regenerate, then render every .svg and .png
```

The `Makefile` passes these flags:

| Flag | Why |
|------|-----|
| `--theme light` | The default, `auto`, adapts the SVG to the viewer's colour scheme |
| `--embed-svg-fonts false` | Keeps labels as `<text>`. The default turned them into PNG images on draw.io 31.4.5 |
| `-s 2` | Renders PNGs at twice the size |
| `--no-sandbox` | [Lets Electron run as root in a container](https://github.com/jgraph/drawio-desktop/issues/338) |

On Linux and in CI, draw.io [needs a display even to export](https://github.com/jgraph/drawio-desktop/issues/146).
Use an `xvfb-run` wrapper:

```bash
printf '#!/bin/sh\nexec xvfb-run -a drawio "$@"\n' > /tmp/drawio-headless && chmod +x /tmp/drawio-headless
```

```bash
make DRAWIO_BIN=/tmp/drawio-headless
```
